# Branding asset handoff — linux-perf-doctor

Artwork is intentionally not included in this repository launch kit. Generate the logo and GitHub social preview with your paid design tool, then place/upload them as follows.

## Suggested file set

- `logo.svg` — primary vector logo, transparent background, square or near-square composition.
- `logo.png` — 512×512 PNG export for contexts that need raster artwork.
- `logo-dark.svg` — optional light mark for dark surfaces.
- `logo-light.svg` — optional dark mark for light surfaces.
- `social-preview.png` — 1280×640 PNG; upload this file through GitHub **Settings → General → Social preview**.

## Visual direction

Project: **linux-perf-doctor**

Core positioning: Read-only Linux performance diagnostics for CPU, memory, PSI, cgroups, processes, disk I/O, and TCP bottlenecks.

Design prompt direction: Create a distinctive, restrained developer-tool identity. Prefer a simple geometric mark that remains recognizable at small sizes, with strong contrast and no generic robot/AI-head clichés. Keep any text minimal; project name typography should remain readable at repository-card sizes.

## Asset paths

Place logo files in this directory. The social-preview image may also be kept here as `social-preview.png` for source control, and then uploaded separately in GitHub settings. GitHub does not automatically read the social preview from this path.
